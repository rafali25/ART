# Published-procedure branch and exact-data requirements

The executed bounded branch is `scripts/reconstruct_art_family.py::replication_workflow`. It is separate from the RT-domain placement branch. Its artifacts are in `replication/`; `commands.jsonl` records actual Windows invocations. The full-length FastTree is generated by DIAMOND → MMseqs2 → FAMSA → FastTree, without using arrays to choose the sequence component.

The paper's full numerical reconstruction cannot be run from the available local data. It requires:

1. The original 12 phage RT protein sequences and their genomic mappings, and the specific 2,019 myRT references.
2. The HMM-retrieved database representatives, including the recorded 350–900-aa replication subset and their source contigs.
3. The original database-cluster membership/retrieval mapping used to add 706 full-length proteins of at least 400 aa. MMseqs clustering of the final set is a different operation and cannot substitute for this membership lookup.
4. Original partner assignments and source annotations for selecting the type-I/≥500-nt-noncoding anchors after longest-contig representatives are chosen.

The available 2,339-entry myRT collection is not silently called the paper's 2,019-entry subset. Of that collection, this branch uses 2,328 canonical proteins and records the excluded entries. Nine baseline RTs plus Machias are available as mapped candidates. The published 823/230/95 counts are reference outcomes, not targets that the code forces.

The following expresses the published operations once those actual inputs exist; it is not an execution log or a claim that they were obtained:

```bash
diamond makedb --in pooled_replication_proteins.faa --db pooled
diamond blastp --query pooled_replication_proteins.faa --db pooled \
  --very-sensitive --evalue 1e-5 --max-target-seqs 0 \
  --outfmt 6 qseqid sseqid bitscore evalue qstart qend sstart send length pident \
  --out all_against_all.tsv

# Select the undirected connected component containing QQM14740.1 using
# DIAMOND links >=140 bits. Retrieve original database-cluster members,
# add mapped members >=400 aa, and retain their nucleotide-source metadata.

mmseqs easy-cluster expanded_component.faa clusters tmp \
  --min-seq-id 0.9 -c 0.8 --cov-mode 0

# Select the member on the longest contig in each cluster. This differs from
# blindly accepting the default MMseqs representative.
famsa longest_contig_representatives.faa full_length_alignment.faa
FastTree -lg full_length_alignment.faa > full_length_tree.nwk

# Only in the replication branch: choose the smallest rooted clade containing
# every eligible type-I + >=500nt noncoding representative. Record the rooting
# assumption; it is not specified in the supplied full-family tree methods.
```

The current small Windows run adds `-k 5 --split-memory-limit 1G` to MMseqs after the default prefilter failed the memory budget. FAMSA 2.5.2, MMseqs2 17-b804f, DIAMOND 2.1.15 and the archived FastTree source/binary hashes are recorded. Those computational settings and input substitutions are explicit limitations on exact reproduction.

`--cluster-members PATH` accepts `representative_key`/`member_key` relations such as the template in `config/art_cluster_members.tsv`. Members must already have sequence and nucleotide mappings in the stage's recorded protein database; an unmapped protein-only member is rejected as a genomic expansion input.

The independent RT-domain tree instead uses Pfam RVT_1 envelopes ±40 aa, MAFFT L-INS-i, 50% occupancy trimming and FastTree LG+Gamma. It is deliberately labelled an approximate sequence evaluation rather than the paper's 774-tip MAFFT/trimAl/IQ-TREE analysis. Architecture-defined clade labels never feed its placement table. NART labels require curated source evidence; the default panel has none.
